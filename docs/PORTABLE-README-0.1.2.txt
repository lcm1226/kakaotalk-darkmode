KakaoDark 0.1.2 Portable - Windows x64
======================================

1. Exit any older KakaoDark through its tray menu before upgrading.
2. Extract this ZIP and run KakaoDark.exe. No separate .NET installation is needed.
3. Keep the EXE in a stable local folder. A shortcut in the current user's Startup folder is optional.

GPU Invert remains visible in normal desktop screenshots and remote desktop sessions,
including Chrome Remote Desktop. No special remote launcher is needed.

Ctrl+H cycles Off, StatusOnly, Full, and Off while KakaoTalk or its control is focused.
GPU OFF retains Privacy with a white mask. Cut removes physical pixels from the bottom;
adjust it for the ad frame on that PC.

The application is unsigned and SmartScreen may warn on first launch.
Settings are stored per Windows user in %LOCALAPPDATA%\KakaoTalkGpuInvertSpike.
Exit normally through the tray. If force termination leaves KakaoTalk clipped, restart KakaoTalk.

See the GitHub 0.1.2 release notes for detailed changes, evidence, and limitations.
